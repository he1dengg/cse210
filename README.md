# CSE 210 Projects

This repository contains the projects and preparatory exercises for CSE 210, a programming course.

## Structure

- **Week 1/**
  - **Prep1/**: Basic C# console application
  - **Prep2/**: C# console application with input/output
  - **Prep3/**: C# program demonstrating loops
  - **Prep4/**: C# program with conditional statements
  - **Prep5/**: C# program using arrays and lists

## Prerequisites

- .NET SDK (version 10.0 or later)
- A C# IDE like Visual Studio or VS Code with C# extensions

## How to Run

1. Navigate to the desired project folder (e.g., `Week 1/Prep1/`).
2. Restore dependencies: `dotnet restore`
3. Build the project: `dotnet build`
4. Run the application: `dotnet run`
